### Задача 7. Диапазон
**Текст задачи:**  
Дана сигнатура метода: `public boolean isInRange(int a, int b, int num);`  
Метод принимает левую и правую границу(a и b) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал true, если num входит в указанный диапазон(включая границы).

**Алгоритм решения:**

3. Условие 2: `num >= b && num <= a`.
4. Если выполняется хотя бы одно из условий (оператор `||`), вернуть `true`, иначе `false`.

## Задание 2. Условия

### Задача 2. Безопасное деление
**Текст задачи:**  
Дана сигнатура метода: `public double safeDiv(int x, int y);`  
Необходимо реализовать метод таким образом, чтобы он возвращал деление x на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. При делении на 0 следует вернуть из метода число 0.

**Алгоритм решения:**
1. Проверить условие: если делитель `y` равен 0, немедленно вернуть `0`.
2. Если `y` не равен 0, выполнить деление `x` на `y`, предварительно приведя `x` к типу `double` для получения дробного результата: `(double) x / y`.

### Задача 3. Тридцать пять
**Текст задачи:**  
Дана сигнатура метода: `public boolean is35(int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал true, если число x делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то вернуть надо false.

**Алгоритм решения:**
1. Сначала проверить "запрещенное" условие: если число делится и на 3, и на 5 одновременно (`x % 5 == 0 && x % 3 == 0`), вернуть `false`.
2. В противном случае (`else`), проверить, делится ли число на 3 ИЛИ на 5 (`x % 5 == 0 || x % 3 == 0`). Если да, вернуть `true`.
3. Если ни одно условие не выполнилось, вернуть `false`.

### Задача 6. Тройная сумма
**Текст задачи:**  
Дана сигнатура метода: `public boolean sum3(int x, int y, int z);`  
Необходимо реализовать метод таким образом, чтобы он возвращал true, если два любых числа(из трех принятых) можно сложить так, чтобы получить третье.

**Алгоритм решения:**
1. Проверить три возможных комбинации сложения двух чисел:
    - `x + y == z`
    - `x + z == y`
    - `y + z == x`
2. Если хотя бы одно из этих условий истинно (оператор `||`), вернуть `true`, иначе `false`.

### Задача 8. Возраст
**Текст задачи:**  
Дана сигнатура метода: `public String age(int x);`  
Необходимо реализовать метод таким образом, чтобы он возвращал строку, в которой сначала будет число х, а затем одно из слов: год, года, лет.

**Алгоритм решения:**
1. Проверить, что число неотрицательное (`x >= 0`).
2. Проверить исключение для чисел, оканчивающихся на 1: если `x % 10 == 1` и `x != 11`, вернуть "год".
3. Проверить исключения для чисел, оканчивающихся на 2, 3, 4: если остаток от деления на 10 равен 2, 3 или 4, и при этом `x` не равно 12, 13 или 14, вернуть "года".
4. Во всех остальных случаях вернуть "лет".

### Задача 10. Вывод дней недели
**Текст задачи:**  
Дана сигнатура метода: `public void printDays(String x);`  
Необходимо реализовать метод таким образом, чтобы он выводил на экран название переданного в него дня и всех последующих до конца недели дней. Вместо if используйте switch.

**Алгоритм решения:**
1. Привести входную строку к нижнему регистру с помощью `toLowerCase(Locale.ROOT)` для нечувствительности к регистру.

3. Для каждого дня недели (от "понедельник" до "воскресенье") вывести его название и **не ставить** оператор `break`, чтобы сработал механизм "проваливания" (fall-through) и вывелись все последующие дни.

## Задание 4. Массивы

### Задача 3. Поиск максимального
**Текст задачи:**  
Дана сигнатура метода: `public int maxAbs(int[] arr);`  
Необходимо реализовать метод таким образом, чтобы он возвращал наибольшее по модулю(то есть без учета знака) значение массива arr.

**Алгоритм решения:**
1. Инициализировать переменную `maxElem` первым элементом массива (`arr[0]`).
2. Запустить цикл `for` по массиву, начиная со второго элемента (индекс 1).
3. На каждой итерации сравнивать модуль текущего элемента `Math.abs(arr[i])` с модулем `maxElem`.
4. Если модуль текущего элемента строго больше, обновить значение `maxElem`.
5. Вернуть `maxElem`.

### Задача 5. Добавление массива в массив
**Текст задачи:**  
Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos);`  
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, который будет содержать все элементы массива arr, однако в позицию pos будут вставлены значения массива ins.

**Алгоритм решения:**
1. Проверить корректность позиции (в коде добавлена защита от некорректного `pos`).
2. Создать новый массив `result` размером `arr.length + ins.length`.
3. Первым циклом скопировать элементы из `arr` в `result` до позиции `pos`.
4. Вторым циклом скопировать все элементы из массива `ins` в `result`, начиная с индекса `pos`.
5. Третьим циклом скопировать оставшиеся элементы из `arr` (начиная с `pos`) в конец массива `result` со смещением на длину `ins`.
6. Вернуть массив `result`.

### Задача 8. Объединение
**Текст задачи:**

Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором сначала идут элементы первого массива(arr1), а затем второго(arr2).
